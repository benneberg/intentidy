## Core Architectural Invariants

### 1. Port & Ingress Constraint
- The application binds strictly to `0.0.0.0:3000`.
- Do not introduce alternate ports or change the listening port. Port 3000 is hardcoded in container infrastructure and reverse proxies.

### 2. Hybrid BFF Runtime
- In **development** (`NODE_ENV !== "production"`), `server.ts` boots via `tsx` and mounts Vite as middleware (`createServer({ server: { middlewareMode: true }, appType: "spa" })`).
- In **production**, Vite builds static assets to `dist/`, and `server.ts` is bundled into `dist/server.cjs` via `esbuild`. The server serves `dist/` statically with SPA fallback.

### 3. Secret Isolation (Zero Client Keys)
- `GEMINI_API_KEY`, `JWT_SECRET`, and `GITHUB_WEBHOOK_SECRET` must **NEVER** be referenced in `src/` or exposed to the client bundle.
- All AI, authentication, and external Git operations occur in `server.ts`.
- Client calls backend proxy endpoints (`/api/gemini/*`, `/api/git/*`, `/api/auth/*`).

### 4. 100% Availability AI Fallback Pattern
- Every endpoint in `server.ts` invoking the Gemini SDK (`@google/genai`) must wrap external calls in try/catch blocks.
- If the SDK fails (missing key, quota exceeded, network timeout), the endpoint must return a structured response generated by a local heuristic rule engine. Never fail hard on AI outages.

### 5. Multi-Tenant Storage Scoping
- PortableCard persistence is partitioned by workspace: `data/workspaces/<workspaceId>/cards.json`.
- State reads and writes must specify the workspace ID (defaults to `"default"`).
- After any card mutation, broadcast the update to connected SSE clients via `broadcastRealtimeEvent(type, payload, workspaceId)`.

### 6. Sandbox & Iframe Constraints
- The UI is rendered inside an iframe in production previews.
- **Never** use synchronous blocking browser APIs (`window.alert`, `window.confirm`, `window.prompt`).
- Use accessible non-blocking React modals or inline alert banners.
